# Support

NeuralOps is maintained as an open-source project. There is no guaranteed response time, hosted-service SLA, paid support plan, or customer-support commitment.

- Use [GitHub Issues](https://github.com/Gowrav-M/neuralops-platform/issues) for reproducible bugs and feature proposals. Include version, environment, steps, expected behavior, actual behavior, and sanitized logs.
- Use repository documentation and source tests to understand local setup and supported behavior.
- Use [GitHub Security Advisories](https://github.com/Gowrav-M/neuralops-platform/security/advisories/new) for vulnerabilities; do not file them as public issues.

Before asking for help with a deployment, check `/health`, `/ready`, relevant environment variables, authentication/database configuration, and the verification commands in the README. Never attach credentials, tokens, or sensitive prompts/outputs.
