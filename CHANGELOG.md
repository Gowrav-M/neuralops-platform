# Changelog

All notable project changes are documented here. This project uses [Semantic Versioning](https://semver.org/) when releases are created.

## Unreleased

### Added

- Workspace-scoped approval preview privacy policy, defaulting to metadata-only; Owner/Admin can enable bounded redacted previews, and switching back clears stored preview content.
- JavaScript MCP and Python OpenAI Agents SDK adapters that authorize and consume action-bound leases before invoking wrapped tool handlers.
- Side-effect-free MCP demo, SDK compatibility notes, integration guide, and approval preview rendering in Agent Command Center.
- Apache-2.0 licensing and open-source community, security, support, roadmap, and contribution documentation.
- A concise repository guide describing the verifiable agent-control lifecycle, local setup, verification, and self-hosting limits.

### Changed

- Focused the next-release roadmap on real runtime integrations, safe approval resumption, and self-hosted developer feedback.
- Replaced launch copy that depended on historical build context or unsupported operational claims with repository-scoped documentation.
